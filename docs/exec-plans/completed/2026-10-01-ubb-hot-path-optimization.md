# UBB 正常路径进一步优化

状态：完成。基于已完成的分配优化继续推进，保留其正式产物作本轮基线。

## 目标

学习 YAUC 的栈顶闭合短路径，进一步减少正常解析的查表、字符串切片和参数逐字扫描。保持 2.0.0 规范、自定义回调、公开 AST 独立性、异常恢复规模与 renderer 惰性契约。

## 步骤

- [x] 保存正式基线，研究 YAUC 栈顶闭合和参数扫描。
- [x] 栈顶直接闭合、按需建立活跃索引、结束标签直接取名称。
- [x] 普通参数值使用原生 indexOf，标签边界跳过普通值，保留等号与逗号状态切换。
- [x] renderer 按需创建可解构函数。无参数正则快路径和短标签特化收益不稳定，未采用；本轮没有合并自定义参数回调。
- [x] 规范与随机差分、恢复压力、正式产物交替基准、全仓 ready。

## 验收

对照上一轮正式产物重复测量，不将源码原型收益当作正式结果。常规和密集路径应可重复改善；异常输入不能回到平方级扫描。不共享公开可变属性，不引入无限缓存、运行时私有接口或行为变化。

## 结果

正式产物同进程交替运行，预热 100 次，11 轮各至少 100 ms，重复两次。相对上一轮产物：常规混合耗时下降约 21%，完整混合约 10%，密集约 15% 至 17%，500 层闭合约 19%，普通引号约 17%，renderer-only 约 4%。90000 字符长无引号 URL 样例从约 0.298 ms 降至 0.034 ms，下降约 89%。纯文本持平；8000 未闭合文本模式和错配恢复在数个百分点范围波动，未见数量级退化。常规混合分配从约 4.75 MB/次降至 4.48 MB/次，减少约 6%。

复跑 YAUC 对照：900 字符混合 7.36 μs 对 7.54 μs；90000 字符混合 736.62 μs 对 749.80 μs，均基本持平。500 层闭合 64.78 μs 对 49.51 μs，仍慢约 31%。同输出简化全流程 926.45 μs 对 1240.94 μs，耗时少约 25%。YAUC AST 与异常恢复语义不同，不能据此宣称所有场景等价超过。

30000 组合输入分别开启与关闭 merge，另有 50000 参数字符随机输入，均与上一轮正式产物零差异；公开子数组与参数别名独立性通过。首次边界跳跃实验被现有引号回归测试捕获错误，修正跨引号内首个 ] 的边界后所有测试通过，未修改断言。

`conformance:check` 和 `vp run ready` 通过，包括 UBB 2043 项、网站 317 项测试、类型、lint、Knip 和生产构建。保持 2.0.0 规范。后续可继续探索内部参数输出融合与 frame 分配，但本轮已验证交付完成，不以未经验证的原型替换公共语义。
