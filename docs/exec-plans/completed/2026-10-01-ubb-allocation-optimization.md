# UBB 分配与正常解析路径优化

状态：完成。基线提交 `12817f6`，正式构建产物已保存在临时研究目录。

## 目标与约束

减少正常闭合的节点、子数组和结束标签索引分配，改善常规与密集解析。保持 2.0.0 规范、公开 AST 独立性、自定义解析回调和 renderer 惰性契约。只修改 TypeScript，性能测量采用相同输入、预热、交替运行与正式产物。

## 验收

全部共享语料及现有回归通过，随机组合 AST 与基线一致。覆盖正常闭合、交叉恢复、EOF、文本模式切换、相邻 empty 结束标签与 Unicode。常规、密集和文本模式混合样例取得可重复改善，不接受明显的异常输入退化。V8 特性仅作为诊断依据，生产代码不使用运行时私有 API。

## 结果

Node 24.18.0、ARM64，保存基线正式产物与新产物同进程交替测试。每项预热 100 次，11 轮交替先后顺序，每轮至少 100 ms，取中位数；独立重跑两次。

| 场景                | 第二次基线 | 第二次优化后 | 两次耗时降幅 |
| ------------------- | ---------- | ------------ | ------------ |
| 74400 字符常规混合  | 0.946 ms   | 0.871 ms     | 8% 至 11%    |
| 96900 字符完整混合  | 1.517 ms   | 1.186 ms     | 20% 至 22%   |
| 90000 字符密集标签  | 2.303 ms   | 1.988 ms     | 13% 至 14%   |
| 500 层闭合嵌套      | 0.081 ms   | 0.073 ms     | 9% 至 14%    |
| 3000 个普通引号参数 | 1.055 ms   | 0.906 ms     | 约 14%       |

常规混合累计分配采样从约 6.47 MB/次降至 4.75 MB/次，减少约 27%，不代表峰值或最终 AST 大小。纯文本基本持平；未闭合 code 两次分别慢 4.8% 和快 0.2%，错配恢复在快 0.8% 与慢 2.2% 间波动，未发现稳定明显退化。宽树恢复快 5% 至 7%。独立进程大输入基准：1.19 MiB median 17.91 ms，11.93 MiB 186.80 ms；与前次非交替记录分别 25.96 ms、257.32 ms，仅作辅助数据。

30000 个独立随机组合输入分别启用与禁用文本合并，正式 AST 与基线零差异；公开节点 children 和 attrs 的修改独立性检查通过。`conformance:check` 与全部 2043 项 UBB 测试通过。`vp run ready` 包含网站 317 项测试、组件挂载、应用构建、类型、lint 和 Knip，全部通过。行为规范仍为 2.0.0。

保留 Map 活跃标签表与 renderer 原实现：对象表、手写循环、字符码替换和惰性函数创建的实验未证明全面稳定获益，未纳入本轮。没有新增无限缓存、对象池或运行时私有 API。后续如继续优化，优先研究长无引号参数的扫描融合。
