# UBB 行为基线与三语言性能重写

## 目标与范围

固定 `739181057294` 的 JS 解析和输出行为，改进共享测试，再由三个独立 agent 分别重写 Rust、Go、C# 实现并优化性能。本轮不修改 JS 生产解析器和 renderer，也不修复其历史边界行为。

语料必须能离线运行，记录版本、来源和摘要。覆盖基础模式、配置覆盖、CC98 tokenizer、Unicode、容错、预设输出，以及固定种子的组合输入。已知 JS 缺陷用带说明的兼容用例固定；未来行为修正单独升级规范。

## 实施步骤

- [x] 完成共享语料、生成校验、测试适配契约和统一基准输入。
- [x] 固定语料后启动三个 agent，各自只修改对应语言仓库。
- [x] 各实现通过语料、本地公共 API 契约测试和语言工具链检查。
- [x] 主 agent 独立差分验证，复测优化前后性能。
- [x] 更新验证记录、遗留项并归档。

## 验证

- 原仓库：`vp check`、UBB 测试与构建、生成器只读检查。
- 三语言：完整 manifest 语料校验、语言原生测试与静态检查。
- 差分：使用独立种子的新增输入，比较 AST、HTML、Markdown。
- 性能：同一输入，分离纯解析与公开预设转换；常驻进程、预热、五轮中位数，计时排除 JSON I/O。实际执行时串行测量，避免三个 agent 同时跑基准干扰。

## 进展

已完成上一轮审查与优化前基准。用户确认原仓库次要问题后续处理，本次集中建设共享行为测试和三语言实现。

规范 1.1.0 已固定为 1749 个行为用例，原有期望值未变。三语言完成直接构建 AST、预设复用和扫描优化，全部通过语料与原生检查。主 agent 另以 5073 个输入完成每语言 15219 项输出对照，Rust 二轮优化后再次对照仍零差异。

## 交付与验证结果

- 原仓库仅修改 conformance、任务命令、生成文件格式化排除项与计划文档，生产解析和输出代码未变。
- 四类语料附 manifest，含来源提交、版本、数量与 SHA-256；生成器支持只读检查。新增独立种子差分程序、JS JSONL runner 和统一 benchmark 输入。
- 原仓库 `vp check` 通过，UBB 1980 测试通过，构建与语料生成检查通过。
- Rust：1749 语料与 9 项 API 测试通过；clippy、fmt、无默认 feature 测试和 Release 构建通过。运行时新增 memchr、stacker，最低 Rust 1.88。
- Go：1749 语料及 API、runner 测试通过；race、vet、gofmt 通过。无外部依赖，最低 Go 1.25。
- C#：1756 测试通过；Release 构建及 format 检查通过。沿用 .NET 8，无新增依赖。
- 永久 `compare.ts` 对三个 runner 各检查 4753 项，全部通过；JS 自检及 benchmark 模式也通过。

## 性能记录

Apple M4 / macOS ARM64，Node.js 24.18.0、Rust 1.92.0 Release、Go 1.27.1、.NET 8.0.31 Release。常驻进程，各项至少预热 0.8 秒，五轮中位数，不含 JSON I/O。纯解析复用 registry，输出使用公开快捷函数。表中单位为微秒，均为最终统一串行测量。

| 输入与操作          |       JS |     Rust |       Go |       C# |
| ------------------- | -------: | -------: | -------: | -------: |
| 42 B 解析           |    0.832 |    0.708 |    0.423 |    0.318 |
| 42 B HTML           |    2.366 |    1.215 |    0.626 |    0.457 |
| 1254 B 解析         |   25.212 |   20.016 |   18.618 |   13.410 |
| 1254 B HTML         |   70.028 |   31.158 |   23.991 |   18.587 |
| 1254 B Markdown     |   54.944 |   32.271 |   23.103 |   17.197 |
| 125400 B 解析       | 3782.481 | 2239.433 | 2254.238 | 2488.079 |
| 125400 B HTML       | 9476.569 | 3439.786 | 2811.081 | 3890.364 |
| 125400 B Markdown   | 7472.789 | 3683.463 | 2670.841 | 3685.280 |
| 125000 B 纯文本解析 |   76.987 |    2.891 |    1.315 |    5.421 |
| 3000 个未闭合 code  | 3875.463 |  234.928 |  433.271 |  330.020 |

优化前同机 1254 B 解析分别为 Rust 58.317、Go 23.126、C# 24.119；42 B HTML 分别为 14.072、33.481、9.708。语言排名随输入变化，本轮没有用输出缓存或跳过 AST 构建换取成绩。

## 遗留项

- 原 JS 的历史 Unicode 下标与对象属性行为按用户范围要求保留，后续修复须升级行为规范。
- C# 泛型 handler 递归渲染仍受运行时栈限制，解析与纯文本提取已验证深层输入；Rust 用 stacker 扩栈，增加 C 工具链构建要求。
- 本轮验证在 macOS ARM64 完成，其他平台和最低运行时版本未实机验证。未测跨语言峰值内存与并发吞吐。
- 三个语言仓库的 GitHub CI、语料自动更新 PR 与发行仍是后续工作。
