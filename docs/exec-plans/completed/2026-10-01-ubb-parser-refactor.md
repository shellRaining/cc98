## 目标与兼容边界

1. 所有位置都来自原始字符串，修复 Unicode 内容丢失及空标签闭合错位。
2. 建立内部词法层，支持 CC98 引号内方括号及成对同类引号转义，明确非法输入恢复策略。
3. 消除上述重复余文搜索、重复祖先查找和宽队列搬移路径。
4. 直接构造最终 AST，优化 CC98 参数对象分配与 renderer 惰性属性实现。
5. 对深度明确能力边界，解决库内纯文本提取的栈溢出，并提供受控的泛型渲染深度处理。
6. 每项输出变化有人工审查的用例，升级本仓库共享行为规范；多语言同步按用户要求延期。

保留 `ubb-core` 的现有导出路径、registry 不可变语义、四种模式、泛型输出、属性结构、raw 和文本节点边界。保留标签族优先级、handler 惰性求值、context 副作用顺序与根级 finalize 次数。词法扫描器作为内部模块，不直接公开可替换 lexer。

默认通用参数语法仍将等号后的内容视为原值，不因 CC98 引号规则而静默改变。阶段一明确是否需要给 registry 增加有限的词法配置，以使 CC98 与自定义方言显式选择规则；仅在无法通过现有配置表达时增加公共选项，并同步类型、文档和 conformance harness。

共享语料中的 `prototype-key` 固定了普通对象赋值导致 `__proto__` 参数丢失的历史行为。参数重写期间保留该行为；是否改成安全的自有属性记录单独列出差异，不能随实现更换静默改变。

## 方案

### 词法扫描与原文位置

新增内部 `src/lexer.ts`，使用按需扫描接口。正文通过 `indexOf("[")` 跳过，标签头内部按选定方言处理引号；token 保存原文区间，不创建全文 token 数组。标签头解析仍由 `parseTag` 执行，registry 负责模式识别。

结束标签在原文中定位，仅对候选标签名执行大小写归一化。不得依赖全文小写字符串长度与原文相同，也不得把自定义 Unicode 标签名限制为 ASCII。

`text` 模式直接读取原文到第一个匹配结束标签，内部同名开始标签不增加深度；`empty` 只消费紧邻结束标签。为结束搜索设置单次解析内的索引或失败缓存，验证多种文本标签交错时也不会反复全量扫描。扫描缓存随调用结束释放，不跨输入缓存 AST 或任意自定义 parseTag 结果。

### 迭代解析与直接 AST

用 frame 栈保存未闭合状态，节点的 children 直接进入最终 AST。维护标签名到最近活跃 frame 的索引，同名 frame 链接前一个同名 frame；结束时只处理实际退出的 frame。

降级使用显式栈或数组游标，不使用 `shift()`、宽数组展开及循环大范围 `splice`。输出必须保持原始深度优先顺序。相邻文本合并延后批量拼接或采用等价策略，避免引入长文本反复复制。

审查错配与 EOF 恢复的累计工作量：已完成子树不得被每层祖先重复展开。复杂度约束针对库内算法，不对用户传入的正则、parseTag、handler 作线性保证。

### CC98 参数解析

把 tokenizer、参数列表转换与 attrs 提取合并为单遍状态机；无参数和普通单参数走等价 fast path。保留空值、位置参数顺序、重复命名覆盖、值内等号和空白规则。新增成对单双引号转义时处理全部转义对，扫描器与参数解析器使用一致规则。

不匹配引号须保留可恢复的原文，且不无限扫描或吞掉后续本可解析标签。具体恢复规则先在阶段一给出输入与期望值，经审查后落实。

### renderer 与深度

将惰性 getter 移到共享实现，缓存状态仍属于单个 props 实例；不复用会被 handler 持有的 props，不跨调用复用 context。`renderNodes` 必须支持解构后调用，保留嵌套调用和重入行为。

纯文本提取改为迭代遍历并一次拼接，测试极深与宽输入。先 profile HTML、Markdown 和 Vue VNode 三类消费方，再评估公共 renderer 优化收益。

任意同步 handler 读取惰性 `content` 会形成 JS 调用链，直接改成后序遍历会提前执行子 handler，改变惰性与副作用顺序。阶段一必须先确定兼容的深度策略：默认候选为显式可配置深度预算，超限时给出可识别错误并在网站完成原文降级，不截断内容；若要求任意深度成功渲染，则需另定义显式调度式 handler 契约，不能以内部循环宣称已解决。此决策及消费方验收是本计划交付的一部分。

## 验收

### 正确性

- Unicode prefix、content 和 empty 三类问题修复，AST 原文与尾部正文完整；覆盖长度变化、代理对及 Unicode 自定义标签名。
- 引号内 `[]`、逗号、等号、单双引号及多组转义符合批准规则；不匹配引号恢复不丢正文。
- 未变更的旧语料逐项一致，所有变化均列名审查；新语料与手写断言一致，摘要及完整 AST/字符串比较通过。跨语言验证延期。
- registry、handler、重入与异常契约通过；深度预算或新契约经过审查，网站超限呈现保留原文。

### 性能与资源

- 使用同机、同运行时、正式构建产物串行测量，消费结果；不计输入生成、构建和 JSON I/O。包含短帖、统一混合语料、纯文本、纯文本块、参数密集及 renderer-only。
- 未闭合 text、孤立结束标签和宽树样例使用 1000/2000/4000/8000 多规模。检查扫描/退出 frame 的工作计数，并核对耗时增长，避免只凭两次计时宣称线性。
- 对 8000 规模三类已复现异常样例，目标中位数至少改善 3 倍；普通短帖与混合解析/输出目标无超过 10% 的可重复回退。门槛在冻结基线后应用，有波动时交替重复采样，不在 CI 中硬编码毫秒断言。
- 大输入独立进程记录 median、p95、节点数、堆与 RSS 增量；内存结果用于对比，不能把调用前后 heapUsed 差值称为峰值。重复解析不同输入验证缓存不会持续增长。
- renderer 惰性优化须对 HTML、Markdown、VNode 各测一次；单一简化字符串原型的 3.5 倍收益不作为验收指标。
